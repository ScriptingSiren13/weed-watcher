About

This project applies the YOLOv8 object detection model to identify and localize weeds in garden images using bounding boxes. A custom dataset was created by capturing and annotating real weed images from my garden. The trained model enables fast and accurate weed detection, supporting applications in precision gardening and automated weed management.

How it works ⌄
  1. Upload a garden or farmland image: Select and upload an image containing weeds or crops from your device.
  2. The YOLOv8 model analyzes the image: Our custom-trained YOLOv8 model runs inference on the uploaded image in real-time.
  3. Weeds are detected and localized: Bounding boxes are drawn around all detected weed instances using object detection.
  4. Results are displayed instantly: You see the annotated image, and optionally, download the result for further use.
